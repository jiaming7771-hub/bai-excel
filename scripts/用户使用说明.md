# Excel小工具箱 — 用户使用说明

## Mac 用户

1. 解压 `Excel小工具箱-macOS.zip`（或直接拿到 `Excel小工具箱.app`）
2. 把 `Excel小工具箱.app` 拖到「应用程序」或桌面
3. 双击打开
4. 若提示「无法验证开发者」：右键图标 → 打开 → 仍要打开  
   或：系统设置 → 隐私与安全性 → 仍要打开
5. 处理结果在桌面文件夹：**Excel小工具箱输出**

## Windows 用户

1. 拿到 `Excel小工具箱.exe`
2. 双击打开（建议放到单独文件夹，例如 `D:\Excel小工具箱\`）
3. 若 SmartScreen 提示：更多信息 → 仍要运行
4. 处理结果在 exe 同目录的 **output** 文件夹

## 能做什么

- Excel 批量合并
- Excel 数据拆分
- 数据清洗（去重/空白/窜行/手机邮箱日期修复）

全程本地处理，不联网、不上传文件，不需要安装 Microsoft Excel。
